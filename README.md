# 🌱 FarmScenario — AI-Powered 3D Farming Simulator

**FarmScenario** is an AI-powered farming simulation that helps users explore crop selection, soil compatibility, water management, and farming scenarios through an interactive 3D environment.

The project aims to make agricultural knowledge more accessible by combining artificial intelligence with interactive visualization.

## 🚀 Features

- **AI Farming Assistant:** Ask farming questions and receive AI-generated guidance.
- **Interactive 3D Farm:** Explore a visual farm environment that responds to farming settings.
- **Crop Intelligence:** Explore crop options and their suitability for different farming conditions.
- **Soil Compatibility:** Investigate how soil types affect crop selection.
- **Water Management:** Experiment with different water availability levels.
- **Farm Scenarios:** Compare normal conditions, drought, and drought with irrigation.
- **AI Crop Diagnosis:** Designed to help users investigate crop health using image-based analysis.
- **Natural-Language Interaction:** Explore farming settings using ordinary language.

## 💡 How It Works

1. Select a crop and configure the farming conditions.
2. Choose soil and water availability settings.
3. Explore the farm in the interactive 3D environment.
4. Ask the AI farming assistant for relevant guidance.
5. Experiment with different scenarios to understand how changing conditions affect the farm.

## 👨‍💻 Getting Started

### Prerequisites

- Node.js and npm
- An internet connection
- API keys for the AI providers configured by the project

### Installation

Clone the repository:

```bash
git clone https://github.com/atorfaruk/farmscenario.git
cd farmscenario
npm install
```

Create a local `.env` file and configure the required AI provider API keys. Refer to the environment variables used in `server.cjs`. **Never publish API keys or commit your `.env` file.**

Start the development server using the scripts defined in `package.json`. Run the frontend and backend as required by the project configuration.

## 🔐 Security

- Keep API keys private.
- Do not commit `.env` files.
- Validate API responses and handle provider failures safely.
